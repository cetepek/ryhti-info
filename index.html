Ryhti

Ryhti näyttää Suomen avoimen rakentamislupa-aineiston selkeästi selattavassa muodossa. Sovellus hakee luvat suoraan viranomaisen avoimesta rajapinnasta, eikä sen käyttöön tarvita tiliä.

Ryhti visar Finlands öppna byggnadstillståndsdata i ett tydligt, bläddringsbart format. Appen hämtar tillstånden direkt från myndighetens öppna gränssnitt, och det behövs inget konto för att använda den.

Mitä sovelluksella voi tehdä

  • Selaa lupia listana ja avaa yksittäisen luvan tiedot.
  • Rajaa hakua kunnan, vuoden, käyttötarkoituksen ja muiden tietojen mukaan.
  • Katso luvat kartalla siellä, missä ne sijaitsevat.
  • Tutki tilastoja siitä, mitä ja minne on haettu lupaa rakentaa.
  • Käytä sovellusta suomeksi tai ruotsiksi — se seuraa laitteesi kieliasetusta.

Vad du kan göra med appen

  • Bläddra bland tillstånd i en lista och öppna ett enskilt tillstånds uppgifter.
  • Filtrera sökningen enligt kommun, år, användningsändamål och andra uppgifter.
  • Se tillstånden på kartan där de finns.
  • Utforska statistik om vad och var det har sökts tillstånd att bygga.
  • Använd appen på finska eller svenska — den följer enhetens språkinställning.

Tietolähde ja lisenssi

Rakentamislupatiedot ovat peräisin Suomen ympäristökeskukselta (SYKE) ja ne haetaan sen avoimista paikkatietorajapinnoista. Aineisto on käytössä CC BY 4.0 -lisenssillä.

Ryhti ei muokkaa lähdeaineistoa. Jos jokin lupa näyttää sovelluksessa puutteelliselta, tieto puuttuu tai on virheellinen myös rajapinnassa.

Datakälla och licens

Uppgifterna om byggnadstillstånd kommer från Finlands miljöcentral (SYKE) och hämtas från dess öppna geodatagränssnitt. Materialet används under licensen CC BY 4.0.

Ryhti ändrar inte källmaterialet. Om ett tillstånd verkar ofullständigt i appen saknas eller är uppgiften felaktig även i gränssnittet.

Tietosuojakäytäntö

Ryhti ei kerää, tallenna eikä jaa mitään käyttäjätietoja. Sovelluksessa ei ole käyttäjätilejä, kirjautumista, analytiikkaa eikä seurantaa.

Sovellus hakee ainoastaan julkista rakentamislupadataa Suomen ympäristökeskuksen rajapinnasta näyttääkseen sen sinulle. Kyselyt kohdistuvat suoraan tuohon rajapintaan, eikä niiden välissä ole Ryhtiin liittyvää palvelinta.

Tietosuojaa koskevat kysymykset voi esittää avaamalla issuen tähän repositorioon.

Sekretesspolicy

Ryhti samlar inte in, lagrar eller delar några användaruppgifter. Appen har inga användarkonton, ingen inloggning, ingen analys och ingen spårning.

Appen hämtar endast offentlig byggnadstillståndsdata från Finlands miljöcentrals gränssnitt för att visa den för dig. Förfrågningarna går direkt till det gränssnittet, och det finns ingen Ryhti-relaterad server emellan.

Frågor om sekretess kan ställas genom att öppna ett issue i det här repositoriet.

Privacy Policy

Ryhti does not collect, store, or share any user data. The app has no accounts, no sign-in, no analytics, and no tracking.

It only fetches public building-permit data from the Finnish Environment Institute (SYKE) open API in order to display it to you. Those requests go directly to that API; there is no Ryhti-operated server in between.

Privacy-related questions can be raised by opening an issue on this repository.
